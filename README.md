Welcome to **iTools-Xsar** – a personal copy to do some development work on myself. My goal is to enhance the Prompt Extra Styler to not only use the JSON for prompt generation, but also generate auto-populated LORA Stacks based on the style selection. This is a personal experiment only, but perhaps if it works, I will bring it to the attention of the developper of the original node-set (and all kudos to him/her for releasing this in the first place).

### **iTools Prompt Styler Extra Xsar 🖌️🖌️:**

Like iTools Prompt Styler, but you can mix up to 4 styles from up to 4 yaml files. check examples folder for basic workflow for this node.

![iTools Prompt Styler Extra](examples/Screenshot6.jpg)

`Example:` here are some examples you just use "cute cat" as a prompt and let `iTools Prompt Styler Extra` do the magic of mixing 4 different styles togather.
